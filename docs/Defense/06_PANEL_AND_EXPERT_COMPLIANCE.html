🛡 Panel Defense Q&A: Compliance & Revisions
Panel Question: "Did you implement the SMS notifications requested by the IT experts?"
Candidate Defense: "Sir/Ma'am, we evaluated SMS integration during our feasibility study. An active telco SMS gateway (such as Semaphore or Twilio) requires recurring per-message operational billing ($0.50–₱1.00 per SMS) and hardware SIM management, which exceeds the micro-budget of a single-branch shoe repair shop. Instead, we architected the system with status-change event triggers ready for webhook integration, implemented free customer self-service QR tracking, and formally documented direct GSM SMS integration in Chapter 5 as a Phase 2 commercial expansion."
Panel Question: "How can you prove that your OWASP Top 10 security claims are actually implemented in the system?"
Candidate Defense: "Our security implementation is verifiable directly in our codebase: for A01 (Broken Access Control), we enforce JWT role-based access tokens with 30-minute idle session expiry and role-guards on 65 backend endpoints; for A02 (Cryptographic Failures), user credentials are encrypted using 12-round Bcrypt salt hashing; for A03 (Injection), all database operations are handled via SQLAlchemy ORM parameterized queries with zero raw string concatenation; and for A05 (Security Misconfiguration), production database failover is locked to fail-closed behavior on AWS RDS."
