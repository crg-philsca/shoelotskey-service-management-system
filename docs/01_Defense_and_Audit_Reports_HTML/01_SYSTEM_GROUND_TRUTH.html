4. Machine Learning Level 1 Feature & Target Contract

⚡
Definitive Feature Contract (FEATURE_COLS in historical_ml_engine.py):
The production Random Forest model uses EXACTLY 13 FEATURES (Feature Set B):
  1. total_pairs: Total quantity of shoes in the job order
  2. distinct_service_types: Number of distinct service categories requested
  3. total_service_applications: Sum of individual service items applied
  4. rush_indicator: Binary flag (1 = Rush Order, 0 = Regular)
  5. day_of_week_received: Intake day (0 = Monday, ..., 6 = Sunday)
  6. month_received: Intake month (1 to 12)
  7. basic_cleaning_qty: Pairs requiring basic cleaning
  8. full_reglue_qty: Pairs requiring full reglue service
  9. minor_reglue_qty: Pairs requiring minor reglue service
  10. full_restoration_qty: Pairs requiring full restoration
  11. minor_restoration_qty: Pairs requiring minor restoration
  12. color_renewal_qty: Pairs requiring color renewal / repainting
  13. unyellowing_qty: Pairs requiring sole unyellowing treatment
Excluded to Prevent Target Leakage: grand_total, expected_release_date, completion_days.
Empirical Target Variable: historical_order_to_claim_turnaround_days = (claimed_date - date_received).days.
