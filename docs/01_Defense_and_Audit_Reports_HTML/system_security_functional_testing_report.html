Security Architecture and Defensive Controls Summary

The Shoelotskey Service Management System integrates multi-layered security engineering:

  • Authentication & Token Security (ST-01 to ST-03, ST-15): Stateless JWT tokens signed with strong HMAC-SHA256 secrets; accompanied by authoritative server-side UserSession tracking enabling instant token revocation on logout.
  • Brute-Force & Lockout Defenses (ST-04, ST-14): Automated 3-failed-attempt account locking with 15-minute cooldown; independent secondary supervisor authorization rate limiting.
  • Access Control Hierarchy (ST-07, ST-08, ST-12): Dual-tier authorization pairing high-level role checks (Owner vs Staff) with fine-grained granular permissions (job_orders.authorize_cancel, inventory.add_stock, etc.).
  • Injection Immunity (ST-10, ST-11): Parameterized SQL queries via SQLAlchemy 2.0 ORM; strict XSS and HTML tag sanitization in customer inputs; React JSX contextual escaping.
  • Audit Logging & Forensic Compliance (ST-13, ST-14): Centralized log_audit() function recording 63 auditable events into database audit_logs table with NIST SP 800-92 denormalized actor snapshots.
