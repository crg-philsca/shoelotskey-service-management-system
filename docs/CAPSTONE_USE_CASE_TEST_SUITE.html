UC-03: Invalid Login & 3-Attempt Security Lock (Negative Test) Pass
Actor & Module
Actor: Unauthorized User / Malicious Actor | Module: Security (backend/main.py)
Preconditions
Login page is accessible. Target account exists.
Main Flow & Alternate Flow
  1. Actor enters an existing username with an incorrect password 1st time. System increments fail counter and displays "Invalid username or password".
  2. Actor fails login 2nd time. Fail counter = 2.
  3. Actor fails login 3rd time. Backend catches 3rd failure and sets locked_until timestamp (15 minutes in future).
  4. Actor attempts login 4th time (even with correct password). System immediately rejects request with HTTP 403 Forbidden.
Expected vs. Actual Result
Expected: Account is locked for 15 minutes after 3 consecutive failed attempts.
Actual: System blocks authentication and displays red toast: "Security Block: Too many failed attempts. Account locked for 15 minutes."
Remarks / Security Standard
Prevents Brute-Force and Dictionary Attacks (OWASP A07 Compliance). Audit trail records "LOGIN_FAILED (account_locked)".

UC-07: Remember Me & Offline Credentials Caching Pass

Actor: Owner / Staff | Module: Offline Auth (Login.tsx)
Preconditions
User authenticates successfully online once while storing credentials in offline cache.
Main Flow & Alternate Flow
  1. User logs in online. System automatically hashes password using SHA-256 (crypto.subtle.digest) and caches encrypted payload in shoelotskey_offline_auth.
  2. Later, internet drops completely (WiFi disconnection or ISP failure).
  3. User re-opens browser and enters username and password in Login screen.
  4. Network fetch fails or throws timeout exception; Offline Fallback Interceptor activates immediately.
  5. System computes SHA-256 hash of inputted password and compares against local cache. Matches and logs user in!
Expected vs. Actual Result
Expected: Seamless login without internet connectivity when valid cached credentials match.
Actual: Successfully logged in offline with notification: "Offline login successful! Operating from local cache."
Remarks / Security Standard
Critical retail resilience feature. Plaintext passwords are NEVER stored in browser storage.
